# Zentryc 

Aplicación Android de gestión de gastos personales desarrollada en Kotlin.

## Funcionalidades
- Registro de ingresos y gastos
- Clasificación por categorías
- Resumen mensual
- Estadísticas con gráficas

## Tecnologías
- Kotlin + Android Studio
- Room (SQLite)
- MVVM (ViewModel + LiveData)
- Navigation Component
- Git / GitHub

## Estructura del proyecto
- `data/model` — Modelos de datos (Expense, Category)
- `data/database` — Base de datos Room y DAOs
- `ui/` — Pantallas y fragmentos
- `utils/` — Utilidades y helpers
